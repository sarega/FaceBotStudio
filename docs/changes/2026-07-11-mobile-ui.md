# Mobile UI Change Log

Release: `0.1.1`  
Date: 2026-07-11

## Scope

This release refines the authenticated admin workspace for phone-sized iOS and Android viewports. It changes presentation only; application state, data flows, API calls, and user actions are unchanged.

## Changes

- Increased mobile navigation and search controls to dependable touch-target dimensions.
- Added safe-area spacing to the app header and mobile navigation drawer.
- Kept the event switcher compact and usable below the desktop breakpoint.
- Reduced mobile-only card visual weight and normalized content spacing.
- Preserved horizontal scrolling behavior for existing scrollable content.
